## 1. Cel / idea

Linie auto-wierszy są dziś **zawsze idealnie poziome** (`RowLine([minX, medianY],
[maxX, medianY])`). Gdy obiekty są ułożone **lekko skośnie** (czasem w górę, czasem
w dół — z góry nieznane), pozioma linia mija skrajne boxy wiersza. Chcemy:

1. Pozwolić linii **lekko się pochylić** — jak najbardziej pozioma (twardy clamp
   **~15°, slope ≤ 0.27**), a jednocześnie łapiąca jak najwięcej boxów.
2. **Zabezpieczenie A:** każdy bbox należy do **max 1 wiersza** (jednej prostej).
3. **Zabezpieczenie B:** auto-linie wierszy **nie przecinają się**.

Typowy układ: 2 wycinki × 3 wiersze × ~5 obiektów; bywa mniej (mniej wierszy,
pojedynczy wycinek). Zmiana ma być mała i nie psuć działającej funkcjonalności.

## 2. Co dokładnie zmieniam w `web/static/app.js`

### A. Dopasowanie skosu
- **Nowa stała** `const MAX_ROW_SLOPE = 0.27;` (~15°).
- **Nowy helper `fitRowLine(group, maxSlope, neighborGap)`**: robust slope (Theil–Sen
  = mediana skosów par punktów), clamp do `maxSlope` **oraz** clamp anty-przecięcie
  `|slope|·halfSpan ≤ 0.4·neighborGap`; linia przez centroid grupy.
- **`clusterRowsInGroup`**: zamiast poziomej linii z `medianY` — policz centroidy Y,
  `neighborGap` (min. odległość do sąsiada) i zwróć `fitRowLine(group, MAX_ROW_SLOPE, gap)`.

### B. Każdy bbox w max 1 wierszu
- **Przepisany `_reassignAllBoxesToRows()`**: przypisanie **wykluczające** — każdy box
  trafia do **jednego** wiersza (linia przecina box i jest **najbliższa** wg
  `line.distanceTo(centerX,centerY)`).
- **`autoDetectRowsInCompartments`** i **`_onMouseUp` (ADD_LINE)**: zamiast per-wierszowego
  `_updateRowBoxes(row)` → globalny `_reassignAllBoxesToRows()` + odfiltrowanie pustych.

### C. Brak przecięć (auto)
- Gwarantowane przez clamp anty-przecięcie w `fitRowLine` (każda linia zostaje w „pasie"
  swojego wiersza).

### D. Smoke testy
- Dodatkowe asercje w `_runSmokeTests` (skos, 1-box-1-wiersz, brak przecięć).

### 3.1 `clusterRowsInGroup` (cała funkcja — stan obecny)
```javascript
function clusterRowsInGroup(boxes, maxRows = 3) {
  if (boxes.length === 0) return [];

  const sorted = [...boxes].sort((a, b) => a.centerY - b.centerY);
  const heights = boxes.map(b => b.height).slice().sort((a, b) => a - b);
  const medianHeight = heights[Math.floor(heights.length / 2)];
  const gapThreshold = Math.max(1, medianHeight * 0.5);

  // Klastrowanie sekwencyjne
  const groups = [[sorted[0]]];
  for (let i = 1; i < sorted.length; i++) {
    const gap = sorted[i].centerY - sorted[i - 1].centerY;
    if (gap > gapThreshold) {
      groups.push([sorted[i]]);
    } else {
      groups[groups.length - 1].push(sorted[i]);
    }
  }

  // Trim do maxRows: zostaw `maxRows` największych (wg liczby boxów)
  let selected = groups;
  if (groups.length > maxRows) {
    selected = [...groups].sort((a, b) => b.length - a.length).slice(0, maxRows);
    // re-sort po Y żeby zachować top→bottom
    selected.sort((a, b) => a[0].centerY - b[0].centerY);
  }

  // Stwórz RowLine dla każdego klastra
  return selected.map(group => {
    const ys = group.map(b => b.centerY).slice().sort((a, b) => a - b);
    const medianY = ys[Math.floor(ys.length / 2)];
    const minX = Math.min(...group.map(b => b.x1));
    const maxX = Math.max(...group.map(b => b.x2));
    return new RowLine([minX, medianY], [maxX, medianY]);
  });
}
```

### 3.2 `_updateRowBoxes` + `_reassignAllBoxesToRows` (metody ImageCanvas — stan obecny)
```javascript
  /** Port _update_row_boxes — przelicza boxes wiersza po edycji linii. */
  _updateRowBoxes(row) {
    row.boxes = this.boxes.filter(b => row.intersectsBox(b));
    row.boxes.sort((a, b) => a.centerX - b.centerX);
  }

  _reassignAllBoxesToRows() {
    for (const row of this.rows) this._updateRowBoxes(row);
  }
```

## 4. Weryfikacja po wdrożeniu

1. `node --check app.js` + smoke testy w konsoli przeglądarki (`[smoke] ... OK`).
2. Serwer działa (http://127.0.0.1:8000); F5 (statyki bez cache).
3. Zdjęcie z lekko skośnymi rzędami → linie delikatnie podążają za skosem, więcej
   boxów w wierszu; zdjęcie „proste" → linie pozostają poziome.
4. Zabezpieczenia: żaden box nie jest w 2 wierszach naraz; auto-linie się nie krzyżują.
5. Regresja: typowe 2×3×5 → etykiety A_1..A_3 / B_1..B_3 i crop bez zmian; pojedynczy
   wycinek / 1–2 boxy → brak wyjątków (1 box → linia pozioma).

## 5. Sygnały, że trzeba rollback

- Boxy „uciekają" do złych wierszy / wiersze kradną sobie obiekty.
- Linie wyraźnie ukośne mimo „prostego" zdjęcia.
- Zmiana liczników A/B lub etykiet na typowych zdjęciach (regresja).
- Wyjątki w konsoli przy auto-detekcji / rysowaniu linii.
→ wtedy: sekcja 3 (ręcznie) lub 3.5 (git).
