## TL;DR — co działa

Aplikacja webowa Turbot na branchu `web_service` jest **w pełni funkcjonalna lokalnie**:

1. **F5** w przeglądarce na `http://localhost:8000/`.
2. Klik obraz w sidebarze "Source" → automatycznie YOLO wykrywa otolity, dzieli na wycinki A/B (largest gap Y), tworzy max 3 wiersze per wycinek (klastrowanie + filtr IQR).
3. Ręczne edycje: tryby `b/l/v/r/d/e`, modal EDIT_LABEL.
4. Wybór "Destination dir" + przycisk "Save here".
5. **"Crop and save (Enter)"** → PNG do destination + adnotacje YOLO `.txt` obok zdjęcia.
6. Cały UI po angielsku.

**Brak**: workflow kalibracji skali (do dyskusji jak ma wyglądać), Dockerfile.

## Decyzje utrwalone (z całej sesji)

1. **Backend bezstanowy** — FastAPI + Uvicorn, stan UI w przeglądarce.
2. **Single-user dev** bez auth.
3. **`DATA_ROOT` env**, jeden volume Docker (kiedy będzie).
4. **Path traversal guard** przez `Path.is_relative_to()` w `safe_resolve`.
5. **Frontend = vanilla JS** + HTML5 Canvas, zero build-step.
6. **Reguła numerowania "od dołu"**: najniższy wiersz w wycinku = `_3`.
7. **Identyfikacja A/B**: largest gap Y. Manual override przez `compartment_override`.
8. **Pasek skali**: `[100, 200, 500, 1000, 2000, 5000 μm]` najbliższe 25% szerokości wycinka.
9. **Auto-detect wierszy**: filter IQR → split A/B → klastrowanie wewnątrz każdej grupy (max 3).
10. **Kalibracja per-katalog** — sidecar `<dir>/calibration.json`.
11. **Pseudo-labelling YOLO** — `.txt` obok zdjęcia źródłowego (active learning loop).
12. **UI w języku angielskim** (komentarze kodu po polsku — dokumentacja techniczna).

## Workflow użytkownika (aktualny stan)

1. Restart serwera (po zmianach Python):
   ```
   cd Otolits_identyfication_program
   DATA_ROOT=. ../.venv-web/Scripts/python.exe -m uvicorn web.app:app --port 8000
   ```
2. Otwórz `http://localhost:8000/` (F5 / Ctrl+F5 dla świeżego JS).
3. Sidebar "Source" → klik na obraz → automatycznie pojawia się:
   - Boxy YOLO (czerwone, później zielone gdy w wierszu).
   - Niebieska ramka A (góra) + fioletowa ramka B (dół).
   - Linie poziome wierszy + etykiety `A_1`, `A_2`, `A_3`, `B_1`, `B_2`, `B_3`.
4. Edycja (opcjonalna):
   - `l` → tryb add line, rysuj dodatkowe.
   - `v` → move (przesuń linię/box).
   - `r` → resize.
   - `d` → del (usuń klikiem).
   - `e` → edit label (klik na linię → modal A/B/auto).
5. Sidebar "Destination dir":
   - Nawiguj do katalogu docelowego.
   - Klik **"save here"**.
6. Toolbar: **"Crop and save (Enter)"**.
7. Alert: `Saved N files. Compartment A: M rows, B: K rows. YOLO annotations: ...`.
8. Pliki:
   - `<destination>/<orig>A_n_m.png` (wycinki PNG).
   - `<source_dir>/<orig>.txt` (adnotacje YOLO).

Przyciski pomocnicze:
- **🧹 Clear rows** — zeruje wiersze i komunikat błędu, **boxy zachowane**.
- **↻ Reload** — pełny reload (re-detect YOLO, przywraca usunięte boxy).
- **Auto-detect (YOLO)** — dorzuca nowe boxy (jeśli ręcznie dodałeś, możesz uzupełnić auto).
